# Интеграции

Подключения Gmail, Microsoft 365, CRM, accounting, ERP, banking и MCP ещё не реализованы. Их карточки на публичной странице — концепция, не работающие integrations. OpenAI API доступен как провайдер модели для текстового ассистента; его ключ привязывается к организации, проверяется через официальный API и шифруется AES-256-GCM.

При реализации бизнес-интеграций нужны OAuth state/PKCE, минимальные scopes, tenant-bound connection records, зашифрованные credentials, отзыв токенов, health status и audit logs. Секреты интеграций нельзя возвращать браузеру или передавать непосредственно агентам.
